# Release Audit — v1.2 Source-Grounded AI Coach

## Added

- optional secure AI Coach mode in the GitHub Pages UI
- provider-agnostic `/api/coach` backend contract
- 18 stage-specific AI evaluation targets
- strict JSON response schema
- source-grounding policy
- scaffold-level architecture
- safety and anti-fabrication rules
- client adapter that stores only the backend URL, not a provider secret
- AI review history alongside local deterministic review history
- source citation rendering for verified coach sources

## Preserved

- fully functional no-backend mode
- local deterministic Research Coach
- Interest Compass
- Boolean Search Builder
- source extraction and synthesis matrix
- design matcher
- data dictionary builder
- statistical decision wizard
- local notebook persistence/export
- GitHub Pages branch deployment

## Not yet included

- a live hosted AI backend
- live scholarly database retrieval
- automatic DOI/reference verification
- full statistical computation backend

These should be implemented only after selecting hosting and data/privacy requirements.
