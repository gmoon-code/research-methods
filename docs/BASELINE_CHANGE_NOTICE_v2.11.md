# Baseline Change Notice v2.11

v2.11 materially changes the student instructional condition.

Two additions can affect student performance and scaffold use:

1. a full accumulated Current Research Snapshot available throughout the process
2. field-specific response-length guidance and concrete model responses across all 113 curriculum fields

The v2.10 pilot freeze was created before any real novice sessions were recorded. That freeze should therefore be treated as **superseded before pilot data collection**.

Use:

`RMS-INSTRUCTIONAL-BASELINE-v2.11`

Do not begin a formal pilot under the old v2.9 instructional baseline if v2.11 is the version students will actually use.

If any future data had been collected under an earlier baseline, they would need to remain identified by that earlier instructional condition.
