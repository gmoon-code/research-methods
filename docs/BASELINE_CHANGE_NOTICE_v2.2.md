# Baseline Change Notice v2.2

v2.2 adds another material instructional-scaffolding change beyond v2.1.

Use the baseline identifier:

`RMS-INSTRUCTIONAL-BASELINE-v2.2`

The methodological engines inherited from v2.1/RC1 remain unchanged, but students now receive more detailed field-specific and option-level guidance. v2.1 and v2.2 should therefore not be treated as identical instructional conditions in a research pilot.
