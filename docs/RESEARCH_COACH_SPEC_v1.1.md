# Research Coach Specification v1.1

## Purpose

The local Research Coach adds stage-specific diagnostics to the 18-stage Research Methods Studio. It is intentionally a reviewer and scaffold, not a paper-writing engine.

## Interaction rule

Student work → local diagnostic → explanation of the problem → next reasoning move → student revision → another review.

The coach does not replace the student's text automatically.

## New tools

- Interest Compass
- Boolean Search Builder
- Source theme tagging
- Theme-by-source Synthesis Matrix
- Research Design Matcher
- Data Table & Dictionary Builder with CSV header export
- Stage-specific readiness diagnostics for all 18 stages
- Persistent review history
- Existing statistical analysis wizard
- Existing citation practice and whole-paper alignment audit

## Diagnostic scores

Scores from 0–100 are heuristic readiness indicators. They are not grades, validated scales, or substitutes for teacher judgment.

## Safety

The local coach flags several high-risk/sensitive categories and advises teacher review. It does not determine legal/ethical approval.

## Future AI mode

A future source-grounded AI coach can be added behind a secure backend. API keys must not be embedded in GitHub Pages. The AI layer should:
- read the student's existing stage state
- ask targeted questions
- cite retrieved scholarly sources for methodological claims
- never fabricate references or data
- preserve first attempts and revisions
- route statistics and safety decisions through validated deterministic components
