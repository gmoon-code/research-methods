# Current Research Snapshot Specification v2.11

## Problem addressed

The previous interface had a small desktop sidebar summary, but it exposed only a few major fields and disappeared at narrower viewport widths. A student working in a later stage could therefore need to navigate backward through several stages to remember the current research question, hypothesis, unit, sampling decision, or analysis plan.

v2.11 adds a full **My Research Snapshot** available from anywhere in the project.

## Access points

Students can open the snapshot from:

- the top research-tool bar
- the compact desktop Current Project card
- an always-visible Current Project Context strip inside every stage

The full snapshot remains available on mobile even when the desktop right sidebar is hidden.

## Snapshot organization

### At-a-glance research chain

The top of the snapshot prioritizes major decisions that students repeatedly need later:

- working research question
- research path
- study/review design
- study rationale
- hypothesis when recorded
- predictor/exposure/manipulated factor when relevant
- outcome
- independent/evidence unit
- population/system
- actual sample/corpus
- primary analysis
- primary quantity/estimand
- main result
- current direct answer
- claim boundary
- limitations
- working title

Only recorded entries are shown.

### Full notebook by research phase

The snapshot then gathers current notebook work under:

1. Question & Direction
2. Literature & Evidence Base
3. Study Design & Method
4. Data, Analysis & Results
5. Discussion & Paper

Each stage displays:

- stage number and path-specific title
- current filled-field count
- ready/working status
- all current visible field responses
- an Open Stage control

Students can optionally show currently empty fields.

### Connected workspace records

The snapshot also retrieves important work that is stored outside ordinary stage fields:

- literature search history
- extracted source records
- structured Methods Lab records
- current data schema
- stored analysis runs
- Writing Lab section drafts
- imported teacher feedback

### Earlier / cross-path responses

Changing the confirmed research path can hide fields that belong to the previous path in the normal stage notebook.

v2.11 does not make those responses disappear from the student's accumulated view.

Previously filled fields that are no longer part of the active path appear under:

**Earlier or cross-path responses**

This supports revision and makes a path change easier to understand.

## Live behavior

The compact snapshot and Current Project Context strip update as the student types.

The full snapshot reads directly from the current project state each time it opens.

## Export

Students can:

- copy the snapshot as text
- download the current snapshot as Markdown

These exports are organizational aids. They do not replace raw data, source PDFs, statistical output, or the manuscript.

## Design rule

The snapshot does not generate, revise, or infer research decisions. It only reorganizes work the student has already recorded.
