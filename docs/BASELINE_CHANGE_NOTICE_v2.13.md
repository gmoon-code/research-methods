# Baseline Change Notice v2.13

v2.13 materially changes the student instructional interface.

The underlying research-method engines remain stable, but the timing and visibility of instructional supports have changed.

v2.13 changes:

- global navigation exposure
- current-stage orientation
- route/progress visibility
- current-work carry-forward
- Stage subsection disclosure
- field-help presentation
- research-path decision presentation
- future-stage access
- downstream review signaling
- Literature/Methods/Data/Writing Lab navigation
- source-evaluation sequencing
- Stage/Lab state synchronization
- save/recovery messaging
- record-deletion recovery
- mobile navigation

These changes can affect:

- time to first meaningful action
- navigation behavior
- scaffold discovery
- terminology confusion
- independence evidence
- error recovery
- teacher-intervention frequency
- students' interpretation of progress

Use:

`RMS-INSTRUCTIONAL-BASELINE-v2.13`

Do not pool student-interface usability or scaffold-use evidence from v2.12 and v2.13 as if they were the same condition.

No real novice pilot session had begun before this redesign in the current project workflow, so v2.13 can become the next pilot candidate without merging an earlier participant wave.
