- ineffective skip-link focus
- inconsistent modal semantics
- nested Escape double-close
- missing root opener restoration across modal replacement
- sub-44 px mobile controls
- 7–10 px instructional microprint
- low-contrast pathway banner text
- enlarged-text skip-link exposure
