# Release Audit — v2.3 Guided Research Pathways

## Added

- top-level Research Path selector
- Stage 4 pathway recommendation from question family
- explicit student confirmation before route-specific filtering
- nine pathway states including Unsure
- core / conditional / cross-design field classification
- progressive reveal of relevant notebook fields
- per-stage Show fields usually not needed control
- preservation of previously entered hidden-field data
- path-specific labels for qualitative, literature-review, meta-analytic, descriptive, observational, quasi-experimental, and mixed-methods work
- path-specific stage titles
- path-specific stage focus explanations
- path-specific core-field completion summary
- path recorded in project snapshot
- navigation labels adapt to path where useful

## Instructional principle

The interface now follows:

research question → confirm research path → show the decisions normally required by that path → reveal cross-design fields only when needed

The system does not assume that every study requires:
- a hypothesis
- an independent variable
- a dependent variable
- a control group
- inferential statistics
- a p-value
- an effect size

## Data preservation

Changing pathways does not delete notebook content. Previously entered values remain visible even if a field is normally hidden under the new path.

## Core-engine status

The underlying deterministic coach, statistics engine, Methods engine, Literature engine, Writing engine, competency engine, and transfer engine are inherited unchanged. v2.3 changes the instructional routing/interface layer.
