# Classroom Pilot & Research-Readiness Release v2.0

## Purpose

v2.0 freezes the current measurement architecture and focuses on whether the complete system is deployable in a controlled classroom pilot.

## New product layers

### Pilot & Recovery Center

- first-use onboarding
- visible save status
- safe local save with error reporting
- periodic rolling browser recovery snapshot for reasonably sized projects
- full project backup envelope with integrity fingerprint
- privacy-minimized sharing copy
- legacy backup import
- classroom deployment checklist
- project-level pilot baseline freeze

### Accessibility and mobile QA

- skip-to-content link
- labeled navigation/aside landmarks
- visible keyboard focus
- escape-to-close dialogs
- dialog roles applied at runtime
- reduced-motion support
- higher minimum control/text sizing
- mobile access to the top research tools, which were previously hidden below 820 px

### Pilot kit

The `pilot/` folder contains teacher implementation, data-management, consent/assent planning, observation, incident/deviation, session-log, and locally authored usability-feedback materials.

## Frozen measurement baseline

The v2.0 manifest hashes the measurement-sensitive components. Those files are unchanged from the v1.9 baseline inherited into this release.

The public transfer bank remains a development/classroom bank. Formal evaluation items remain private.

## Research-readiness boundary

This release is suitable for a feasibility/usability pilot after applicable school/institutional approval. It does not make the provisional competency rubric validated, and it does not turn heuristic diagnostic scores into research outcomes.
