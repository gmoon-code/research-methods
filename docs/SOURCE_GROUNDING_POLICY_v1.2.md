# Source-Grounding Policy v1.2

## Purpose

The AI Research Coach may explain general research-methods concepts from a curated knowledge base and may use external literature only when the source has actually been retrieved and verified.

## Source classes

### Class A — Curated methodology sources

Preferred for general methodological claims.

Examples include:
- National Academies science-practice frameworks
- American Statistical Association / GAISE materials
- APA style guidance or institutionally accepted APA references
- discipline-specific reporting standards
- peer-reviewed methodology articles and textbooks selected by the teacher

### Class B — Student-selected sources

The coach may analyze a paper the student has supplied or added to the project. It must distinguish:
- what the source directly reports
- the student's interpretation
- the coach's methodological inference

### Class C — Newly retrieved literature

The coach may use newly retrieved scholarship only after source retrieval. Each literature-derived claim must carry a verified citation record in the coach response.

## Prohibited behavior

The coach must not:
- manufacture a citation from a title fragment
- invent a DOI
- create plausible-sounding authors
- cite a search-result snippet as if the full paper was read
- attribute a finding to a paper unless the source supports it
- fill missing numerical results from contextual clues
- claim a literature gap solely from a small search result set

## Literature review mode

When the student asks for literature-review help, the AI should first diagnose the student's synthesis. It may suggest:
- missing comparison dimensions
- search terms
- organizational structures
- claims that need evidence
- places where multiple studies should be synthesized

It should not generate a source-rich literature review using unverified citations.

## Citation integrity

The final paper must remain auditable:
claim → supporting source → verified bibliographic record.
