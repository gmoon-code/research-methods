## Methodological correction

Experimental research is no longer the implicit exemplar for rigorous research.

Each path shows different requirements for

- constructs/variables
- units
- sampling
- evidence
- analysis
- validity/trustworthiness
- causal/generalization boundaries

## Core-engine status

Coach, Methods, Statistics, Literature, Writing, Transfer, Competency, Pathway, Rescue, novice-friction, and the v2.7 experimental exemplar content are preserved. The exemplar state/UI layer and exemplar bank are expanded.
