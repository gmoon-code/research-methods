# Guided Research Pathways v2.3

## Purpose

v2.3 reduces cognitive overload by changing the student interface after the research design path is known.

A student doing qualitative research should not be required to interpret experimental IV/DV or p-value fields simply to proceed. A literature-review student should not be confronted with participant-sampling fields as though new participants were being recruited. A descriptive study should not be forced to invent a formal hypothesis.

## Available pathways

1. Descriptive quantitative
2. Observational / correlational
3. Experimental
4. Quasi-experimental
5. Qualitative
6. Literature review
7. Meta-analysis
8. Mixed methods
9. Unsure / still deciding

The student's Stage 4 question family produces a recommendation. The system does not silently force the route; the student confirms or chooses another defensible path.

## Progressive reveal

Each pathway classifies notebook fields as:
- core
- conditional
- usually not needed for this path

Fields that are usually not needed are hidden by default after the pathway is chosen.

They remain available through:
`Show fields usually not needed for this path`

Any field that already contains student work stays visible even if the pathway changes.

Changing pathways never deletes data.

## Path-specific terminology

Shared notebook fields are relabeled when the underlying reasoning differs.

Examples:
- Qualitative `experimental unit` becomes participant/document/observation unit.
- Literature review `sample` becomes included study/report set.
- Literature review `instrument` becomes study matrix/extraction/screening tools.
- Meta-analysis `row unit` becomes extracted effect-size row.
- Observational `predictor/IV` becomes measured predictor or exposure.

## Stage flow

Later stages receive pathway-specific focus statements.

Qualitative stages 9–15 become:
- choose qualitative design
- define phenomenon/evidence/unit
- plan sampling/data collection quality/ethics
- lock qualitative protocol/coding plan
- prepare qualitative corpus
- analyze qualitative evidence
- write qualitative findings

Literature-review stages 9–15 become:
- choose review design
- define concepts/unit of inclusion
- plan search/screen/extraction/appraisal
- lock review protocol/study matrix
- organize included evidence base
- conduct synthesis
- write review Results

Equivalent route-specific framing is provided for descriptive, observational, experimental, quasi-experimental, meta-analytic, and mixed-methods projects.

## Safety boundary

Progressive reveal is an instructional interface. It does not remove methodological responsibility. Students can always reveal cross-design fields, and teachers can require additional decisions when a particular project needs them.
