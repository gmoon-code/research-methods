# Concrete Response Examples Specification v2.11

## Problem addressed

Field definitions can be technically correct while leaving a novice unsure about:

- how much to write
- whether a phrase, sentence, list, or paragraph is expected
- how specific the answer should be
- what level of methodological detail belongs in the field

v2.11 adds an explicit response model for all 113 curriculum notebook fields.

## Always-visible response cue

For text and textarea fields, the student sees:

- the expected response shape
- a typical working length
- a live current word count

For example:

> Typical working response  
> one complete sentence, sometimes two · about 15–50 words  
> 27 words currently

The length range is an instructional guide and is explicitly not a grading requirement.

Select fields receive a choice-format cue instead of a word count.

## Expanded field guidance

Opening field help now shows:

### How much should I write?

A field-specific amount/shape guide.

### Too vague

A short example showing insufficient specificity.

### Good working response

An actual concrete response from another research context at an appropriate level of detail.

### More detailed response

Used for fields where beginners commonly need to see a fuller explanation, including procedure, operational definitions, sampling, analysis justification, Results, limitations, Discussion, literature-review drafting, and abstract writing.

### Why this is the right kind of response

An explanation of what the example is doing methodologically.

## Coverage

`113 / 113` curriculum notebook fields have:

- expected response shape
- typical working length
- too-vague contrast
- concrete good working response
- explanation of why the response fits the field

Longer detailed examples are added to selected high-friction fields.

## Authorship boundary

Examples are models.

There is no copy/apply-to-project control.

The example system does not inspect the student's topic and generate a completed response for them.

The student still makes the project-specific research decision.

## Relationship to Progressive Help

The response examples are ordinary instructional guidance available before escalation.

Progressive Help remains the separate scaffold ladder for students who remain stuck after reading the ordinary guidance.
