# Release Audit — v1.3 Literature Research Workspace

## Added

- dedicated Literature Workspace accessible from the top navigation
- reproducible search log
- source screening status and reason
- expanded bibliographic records
- bibliographic verification flag
- TRAPP source evaluation
- study extraction completeness
- study matrix export
- theme evidence with support/conflict/mixed/background stance
- theme-by-study synthesis matrix
- evidence map

- literature-review paragraph planner
- literature outline Markdown export
- source IDs for auditable citations within the workspace
- Stage 6 Research Coach now considers screening, TRAPP completion, and theme evidence

## Preserved

- 18-stage research curriculum
- deterministic Research Coach
- optional secure AI Coach interface
- no public API keys
- design matcher
- data schema builder
- statistics wizard
- GitHub Pages compatibility

## Still not included

- automatic scholarly database search
- DOI metadata import
- PDF parsing inside the deployed site
- automatic reference verification
- a live hosted AI backend

These remain future steps because a static GitHub Pages site cannot securely provide all of them by itself.
