# Competency Model Design Note v1.8

The competency architecture is intended to represent recurring research decisions across the full project, not isolated worksheet completion.

The model deliberately distinguishes performance under support from performance before support. This is necessary because a student can produce a strong research question, method, or statistical explanation after substantial scaffolding without yet being able to make the same decision independently.

The model also treats teacher judgment as a separate evidence stream. A teacher may have access to oral explanation, classroom observation, drafts, and methodological context that the local rule engine cannot evaluate.

## Evidence interpretation

A useful evidence pattern may look like:

- IR = 1
- SP = 3
- SL = 3

This means the student's first independently captured evidence was weak, the current supported work is strong, and a structured decision scaffold was used. That pattern suggests instructional progress and remaining dependence on support. It should not be collapsed into a single “2.3” ability score.

Another pattern may be:

- IR = 3
- SP = 3
- SL = 1

This is stronger evidence of independent performance within the current project context.

## Transfer remains unmeasured

v1.8 does not claim transfer. A later release should use reviewed novel research scenarios that differ in surface topic while requiring the same underlying reasoning. Transfer performance should be reported separately from project performance.
