- Research Coach panel on every stage

- persistent review history
- Interest Compass
- Boolean search builder
- source theme tags
- synthesis matrix
- research design matcher
- data dictionary/schema builder
- CSV header template download

- literature draft heuristic checks
- Results/Discussion claim-language checks
- abstract/title checks
- final alignment scoring

## Preserved

- fully static GitHub Pages architecture
- no exposed API keys
- local browser storage
- Markdown notebook export
- JSON backup
- 18-stage curriculum
- deterministic statistics wizard

## Important limitation

The local coach is a transparent heuristic system. It cannot understand arbitrary student prose at expert human depth. A later AI-assisted mode should use a secure server-side proxy and must remain source-grounded.
