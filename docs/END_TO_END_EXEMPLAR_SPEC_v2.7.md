# End-to-End Beginner Walkthrough & Exemplar Project System v2.7

## Purpose

The earlier guidance explains individual decisions. v2.7 adds a second kind of support: one complete parallel research project that shows how decisions accumulate over time.

The exemplar is optional and never fills the student's project.

## Exemplar

**Radish Salinity Experiment**

Path: Experimental

Status: Synthetic instructional exemplar

Literature records: real and bibliographically verified

Procedure, dataset, statistical output, and findings: synthetic teaching material

## Stage structure

All 18 stages show:
- where the exemplar is at that point
- what changed
- step-by-step reasoning
- the decision retained
- an alternative explicitly rejected
- the resulting notebook entries
- how that decision constrains the next stage
- prompts for comparing the exemplar with the student's own project

## Central methodological thread

The example deliberately emphasizes experimental-unit reasoning.

Treatment is assigned to 18 Petri dishes.

Five seeds inside each dish are subsamples.

The package contains:
- 90 synthetic seed-level rows
- 18 dish-level analysis rows

The primary analysis uses the 18 dish rows.

This prevents the exemplar from quietly teaching pseudoreplication.

## Independent-evidence protection

Opening an overview does not expose the worked stage content.

Before the first view of a worked stage, the site warns that the exemplar counts as Level 4 support.

If the student continues:
- the stage is recorded as Level 4 worked-example support
- Learning Analytics receives the support event
- any later independent checkpoint correctly sees the prior support

If an eligible checkpoint already exists, the earlier checkpoint remains unchanged.

## Bundle support

Opening a full worked resource records Level 4 support for the stages it exposes.

Verified source-record bundle:
Stages 3, 5, 6, 7, 8

Synthetic data/analysis bundle:
Stages 12, 13, 14, 15

Complete paper bundle:
Stages 8, 12, 15, 16, 17, 18

## Cross-path warning

The exemplar follows an experimental path.

If the student's confirmed path is observational, quasi-experimental, qualitative, literature review, meta-analysis, or mixed methods, the modal explains which parts of the exemplar should not be copied into that path.

## No copy mechanism

There is deliberately no “use this answer” or “copy to my project” control.

Students can save a comparison note about what is similar, different, or unresolved in their own project.
