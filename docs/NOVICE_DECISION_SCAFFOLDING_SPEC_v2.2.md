# v2.2 Novice Decision Scaffolding

v2.2 extends the v2.1 high-scaffolding release after a stage-by-stage novice audit.

The design assumption is that a learner may be encountering research methods for the first time.

## New support layer

Every stage now includes a worked reasoning walkthrough in addition to the existing explanation, steps, examples, terms, and stuck route.

Every notebook field now has specific guidance. No generic fallback field help remains.

Decision fields now explain the meaning of each option and provide questions that help students determine which option describes their project.

## Key decision guides

Guidance is provided for:
- question family
- study rationale/gap type
- primary design
- whether a formal hypothesis is appropriate
- citation style requirement
- assignment/exposure structure
- same-unit repeated structure
- sampling method
- human-participant/identification/sensitive-data/intervention gates
- source type
- screening status
- literature-theme stance
- data/design structure
- outcome type
- Pearson versus Spearman
- Welch versus classical ANOVA
- chi-square versus Fisher exact

## Scaffold boundary

The guidance supports reasoning but does not auto-populate the student's research decision. Worked examples are explicitly presented as reasoning models.
