## Critical validity safeguards

- public candidate tasks are explicitly not described as held-out
- automated free-response transfer scoring is not claimed
- supported revisions are not scored as independent evidence
- inter-rater reliability is not described as construct validity
- formal evaluation items must stay outside the public repository
- development and locked evaluation sets must remain separate
