# Baseline Change Notice v2.1

The previous `RMS-PILOT-BASELINE-v2.0` instructional condition is superseded for a future classroom pilot if v2.1 is adopted.

The underlying methodological, coach, competency, transfer, writing, and statistics engines remain inherited from RC1, but the amount and form of instructional scaffolding has changed substantially.

Use:

`RMS-INSTRUCTIONAL-BASELINE-v2.1`

Do not pool v2.0 and v2.1 student evidence as if students received the same instructional treatment.
