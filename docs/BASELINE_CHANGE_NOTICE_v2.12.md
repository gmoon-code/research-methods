# Baseline Change Notice v2.12

v2.12 adds an always-available conversational AI helper.

This can materially change:

- when students request help
- the amount and timing of scaffolding
- independent-checkpoint eligibility
- terminology clarification
- design/statistics reasoning
- writing support
- teacher intervention requirements

Use:

`RMS-INSTRUCTIONAL-BASELINE-v2.12`

A pilot using the chatbot should record whether AI was enabled and freeze the approved backend configuration for the wave.

The v2.11 pilot materials are superseded before real novice data collection.
