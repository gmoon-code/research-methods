# Methods & Study Design Laboratory v1.4

## Purpose

Teach students how a research question becomes a defensible method before data collection begins.

The uploaded Part 3 Methods guide provides the backbone:
participants/units → variables → instruments → procedure → analysis → ethics.

The uploaded Part 4 Data Collection guide adds the key structural rule:
the research question determines the data table, every row has a defined unit, and every column has a defined measurement.

v1.4 expands these ideas into nine interactive method-design workspaces.

## Nine tabs

1. Design
2. Variables and operational definitions
3. Experimental/observational units and replication
4. Sampling and recruitment
5. Measurement quality
6. Ethics, safety, privacy, and authority
7. Procedure
8. Data table and dictionary
9. Pre-collection audit and protocol lock

## Design terminology

The lab changes terminology by design.

Experimental / quasi-experimental:
- manipulated independent variable
- outcome/dependent variable
- conditions/levels
- comparison/control condition
- experimental unit
- assignment mechanism

Observational correlational:
- predictor/exposure
- outcome
- covariates/confounders
- observational unit

Descriptive:
- descriptive variables
- grouping/context variables

Qualitative:
- participant/context descriptors
- prompts/observation domains
- qualitative unit of analysis

The software therefore does not force every study into IV/DV language.

## Replication and pseudoreplication

The lab separates:
- independent units
- repeated measurements/trials per unit
- subsamples/technical measurements per unit
- one spreadsheet row

Repeated measurements or subsamples do not automatically increase the number of independent units.

## Sampling versus assignment

Sampling determines how units enter the study and constrains generalization.
Assignment determines how experimental units receive conditions and influences causal comparability.

These processes are explicitly separated.

## Measurement planning

For each central construct students record:
- instrument/procedure
- operational definition
- units/scale/categories
- timing/frequency
- reliability/consistency plan
- validity evidence/rationale
- calibration/scoring/blinding notes

## Ethics/safety

The lab screens:
- human participants
- minors
- identifiable/linkable records
- sensitive data
- human interventions
- authority to assign/manipulate
- risk
- consent/permission
- assent/guardian permission when applicable
- withdrawal/voluntariness
- confidentiality/deidentification
- data storage/retention
- procedure-specific safeguards

The screen is educational. It does not grant formal research approval.

## Protocol lock

A protocol can be locked only after critical method issues are resolved. Later versions can be amended, but prior locked versions remain stored. This supports transparent distinction between planned and post-data decisions.
