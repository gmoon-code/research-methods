# Radish Salinity Exemplar

This folder belongs to the v2.7 worked-exemplar system.

The literature citations are real and verified. The experimental procedure details, data, statistical output, and findings are synthetic teaching material.

Files

- `SYNTHETIC_SEED_LEVEL_DATA.csv` preserves five seed subsamples per dish.
- `SYNTHETIC_DISH_LEVEL_ANALYSIS_DATA.csv` contains the 18 independent dish-level observations used for the primary analysis.
- `SYNTHETIC_ANALYSIS_OUTPUT.json` stores the exact synthetic statistical output.
- `VERIFIED_SOURCE_RECORDS.json` stores the verified literature records used in the exemplar.
- `COMPLETE_SYNTHETIC_EXEMPLAR_PAPER.md` shows how the full paper fits together.

The central methodological point is that treatment is assigned to dishes. The seed rows therefore cannot be treated as 90 independent treatment replicates.
