# Consent, Assent, and Permission Planning Checklist v2.0

Use this only after the appropriate school/institutional authority determines what approvals are required. Requirements vary by jurisdiction and by whether the activity is instruction, evaluation, or research.

- [ ] Activity classification has been determined.
- [ ] Required institutional/school review has been identified.
- [ ] Participation in research data collection, if any, is distinguishable from required coursework.
- [ ] A nonparticipation route does not create an academic penalty where voluntariness is required.
- [ ] Student-facing explanation states what data are collected and why.
- [ ] Parent/guardian permission requirements for minors have been determined.
- [ ] Student assent requirements have been determined.
- [ ] Teacher/researcher dual-role and possible coercion have been considered.
- [ ] Sensitive or identifiable information has been minimized.
- [ ] Withdrawal procedure is documented.
- [ ] Data storage, access, retention, and deletion are explained accurately.
- [ ] AI or third-party processing, if any, is disclosed as required.
