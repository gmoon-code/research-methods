# Baseline Freeze Policy v2.0

## Baseline rule

The classroom pilot baseline is identified by the hashes in `FROZEN_BASELINE_MANIFEST_v2.0.json`.

Measurement-sensitive files include competency definitions/scoring logic, transfer tasks, deterministic diagnostic rules, research-method routing, statistical rules/calculations, writing diagnostics, and stage prompts.

## During a pilot

Do not silently modify a measurement-sensitive file after data collection begins.

If a serious defect requires a change:

1. document the defect and affected students/sessions
2. preserve the original release
3. create a new version/baseline manifest
4. record which observations occurred under each baseline
5. determine whether affected analyses need stratification, exclusion, sensitivity analysis, or descriptive-only reporting

Cosmetic or accessibility fixes that cannot change student decisions/scores should still be logged, although they may not require a new measurement baseline depending on the research protocol.
