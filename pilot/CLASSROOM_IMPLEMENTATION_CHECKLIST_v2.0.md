# Classroom Implementation Checklist v2.0

## Technical readiness

- [ ] Site opens from the intended GitHub Pages URL on school devices.
- [ ] Students can reach all top navigation tools on desktop and mobile.
- [ ] Local browser storage is allowed and is not automatically cleared during the class period.
- [ ] Full backup download and restore have been tested on a non-sensitive sample project.
- [ ] Teacher Dashboard packet import/export has been tested.
- [ ] If AI is enabled, only an approved secure backend URL is used.

## Instructional readiness

- [ ] Teacher has reviewed the 18-stage pathway and five Journey milestones.
- [ ] Independent checkpoint expectations are defined.
- [ ] Teacher approval checkpoints are defined.
- [ ] Expectations for citations, source verification, data integrity, and acceptable AI use are explicit.
- [ ] Public transfer tasks are labeled practice/development items, not a secret test.

## Privacy and ethics readiness

- [ ] Student naming convention is defined.
- [ ] Approved storage location for raw data/backups is defined.
- [ ] Human-participant/sensitive-data escalation procedure is defined.
- [ ] Consent/assent/permission requirements, if any, have been determined by the appropriate authority.
- [ ] Teacher knows that the website does not provide ethics approval.

## Measurement freeze

- [ ] v2.0 baseline manifest archived.
- [ ] Pilot start date recorded.
- [ ] Measurement-sensitive changes will trigger a new version or documented deviation.
- [ ] Any private validation bank is stored outside the public repository.
