# v2.11 Pilot Operations

This folder rebases the v2.10 real-novice pilot protocol onto the new student-facing baseline:

`RMS-INSTRUCTIONAL-BASELINE-v2.11`

The previous pilot had not begun, so no participant data need to be pooled or migrated.

Before any participant session:

1. review the v2.11 application
2. run the freeze verifier
3. repeat the teacher round-trip rehearsal
4. resolve privacy/consent/research-use requirements
5. complete the pre-flight checklist
6. run the readiness checker
7. begin only after GO

The new snapshot and response-example systems are part of the instructional condition and should remain frozen during a pilot wave.
