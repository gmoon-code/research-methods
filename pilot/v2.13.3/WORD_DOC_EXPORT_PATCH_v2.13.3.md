# Word Document Export Patch v2.13.3

Student-readable text exports now download as Microsoft Word-compatible `.doc` files instead of Markdown `.md` files.

This includes the research notebook, Research Snapshot, literature/method/results planning records, paper draft, and competency report.

JSON exports remain JSON because they are used for backup, recovery, data exchange, or machine-readable records.

The Research Chat, guided route, Snapshot, Help system, research-method engines, and scaffold logic are unchanged.
