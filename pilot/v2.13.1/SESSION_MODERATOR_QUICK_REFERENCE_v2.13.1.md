# Session Moderator Quick Reference v2.13.1

## Before participant arrives

- freeze verification PASS
- pre-flight checklist reviewed
- approved participant code ready
- correct scenario card selected
- observer event log open
- backup/recovery procedure available
- recording status confirmed

## Opening script

> You are testing a research-planning website. I am interested in where the website is clear and where it becomes confusing. You are not being graded. Use any help built into the site. I may stay quiet because I want to see whether the website itself helps.

## External support

**0** no observer help

**1** neutral navigation prompt

> Tell me what you are trying to do right now. Where would you look in the interface for help with that?

**2** repeat/clarify the task wording only

**3** concept rescue, exact wording logged

## Never give away

- correct research path
- correct variable/unit label
- correct statistical test
- correct methodological answer
- where a hidden control is located before observing whether the student can find it

## Record immediately

- TERM confusion
- NAV confusion
- PATH confusion
- METHOD/STAT misconception
- built-in help used
- observer prompt
- save/recovery problem
- exemplar copying attempt
- accessibility problem
- task completion/abandonment

## End-of-session

- post-task questions completed
- session log closed
- deviations recorded
- issues copied to issue log
- full backup handled according to approved data plan
- freeze verification rerun
