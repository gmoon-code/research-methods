# v2.13.2 Pilot Operations

This folder is the pilot-preparation kit for:

`RMS-INSTRUCTIONAL-BASELINE-v2.13.2`

v2.13.2 changes the student interface substantially while retaining the underlying research-method engines.

The pilot candidate now includes:

- a persistent five-phase research route
- current Stage and progress visibility
- stage-specific carry-forward context
- My Research Snapshot
- focused Stage subsections
- one primary forward action
- unified Help
- recommendation-first research-path support
- sequential Literature/Methods/Data/Writing Labs
- dependency-aware Needs review states
- synchronized Stage/Lab decisions
- student/teacher interface separation
- the v2.12 Ask Research AI system

Before the first participant:

1. run `scripts/verify_pilot_freeze.py`
2. repeat the teacher backup/restore and review-packet rehearsal
3. verify student mode on the exact target devices
4. decide and freeze the AI condition
5. document privacy/consent/research-use decisions
6. review `STUDENT_FLOW_OBSERVATION_ADDENDUM_v2.13.2.md`
7. complete every PRE_FLIGHT_CHECKLIST item
8. run `scripts/check_pilot_readiness.py`
9. begin only after GO

No real novice pilot session had begun under v2.12 before this redesign.
